Ocean Wallet uses API keys to authenticate every request. Include your API key in the `Authorization` header as a Bearer token on each call you make to the API. Requests that are missing a key, or that supply an invalid or revoked key, will receive a `401 Unauthorized` response and will not be processed.

## Generating an API Key

<Steps>
  <Step title="Log in to the dashboard">
    Go to [app.oceanwallet.com](https://app.oceanwallet.com) and sign in to your account.
  </Step>
  <Step title="Open API Keys settings">
    Navigate to **Settings → API Keys** from the left-hand sidebar.
  </Step>
  <Step title="Create a new key">
    Click **New API Key** in the top-right corner of the API Keys page.
  </Step>
  <Step title="Name your key">
    Give the key a descriptive name (e.g. `production-backend` or `staging-payments`) so you can identify it later.
  </Step>
  <Step title="Copy and store the key securely">
    Copy the key immediately and store it in a secrets manager or environment variable. The full key value is shown **only once**.
  </Step>
</Steps>

<Warning>
  You cannot retrieve your API key again after closing the creation dialog. If you lose it, generate a new key and revoke the old one immediately to prevent unauthorized access.
</Warning>

## Using Your API Key

Pass your API key in the `Authorization` header as a Bearer token on every request.

```bash cURL
curl https://api.oceanwallet.com/v1/wallets \
  -H "Authorization: Bearer ocn_live_yourapikey"
```

The examples below show how to do the same in Node.js and Python:

<CodeGroup>

```javascript Node.js
const response = await fetch('https://api.oceanwallet.com/v1/wallets', {
  headers: {
    'Authorization': 'Bearer ocn_live_yourapikey',
    'Content-Type': 'application/json'
  }
});

const data = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://api.oceanwallet.com/v1/wallets',
    headers={'Authorization': 'Bearer ocn_live_yourapikey'}
)

data = response.json()
```

</CodeGroup>

## API Key Scopes

When you create an API key, you assign it one or more scopes that control what actions it can perform. Grant only the scopes your integration actually needs.

| Scope | What it allows |
|-------|----------------|
| `read` | View wallets, balances, and transaction history |
| `write` | Send funds and create payment links |
| `admin` | Manage webhooks and revoke API keys |

## Revoking a Key

To revoke a key, go to **Settings → API Keys**, click the key you want to remove, then click **Revoke**. Revocation takes effect immediately — any in-flight requests using that key will fail with a `401 Unauthorized` response. Always revoke keys that are no longer in use or that you suspect have been compromised.

## Test vs. Live Keys

Ocean Wallet provides two types of API keys so you can develop safely before going live.

- **Test keys** — prefixed with `ocn_test_` — route requests to a sandboxed environment. No real funds are moved, and test transactions are isolated from your live data.
- **Live keys** — prefixed with `ocn_live_` — operate against real accounts and affect actual funds.

Always use test keys during development and integration testing. Switch to a live key only when you are ready to process real transactions in production.

<Note>
  Rate limits are enforced per API key, not per account. If you have multiple keys on the same account, each key has its own independent 100 requests-per-minute quota.
</Note>
